每条订单还可在“订单查询”工具中输入相同 ID 核对结构化结果。要串测申请、客户确认、ADMIN 审批与沙箱执行，建议从 `001` 开始，在订单卡片按流程操作；只对一条订单走完整退款，其余订单就仍是干净的测试样本。审批通过不等于资金成功，需等沙箱最终结果回写。

注意：聊天中的“能退款吗”只是一条问答；实际资格以订单卡片的退款评估接口为准。测试订单没有商品明细字段，不适合询问商品名称或 SKU。只有当前 CUSTOMER 账号拥有这批订单；换账号查询应返回 `404`。

如需为另一次验收创建新批次，可在复查当前数据后调整 [`seed-chat-orders.mjs`](../packages/database/prisma/seed-chat-orders.mjs) 的批次编号。脚本只允许写本机 `ecommerce_agents`，整批事务创建；再次执行同一编号会停止，不覆盖已有订单或退款。
